## 第12页｜为什么使用 WebSocket

### 重点说明

普通 HTTP：

```text
浏览器 → 请求 → 服务端
浏览器 ← 响应 ← 服务端
```

实时课堂：

```text
浏览器 ⇄ WebSocket ⇄ FastAPI
                         ↓
                      YOLOv8
```

### 使用 WebSocket 的原因

实时检测需要持续发送图像帧和返回检测结果，长连接更适合这种连续通信场景。

### 页面结论

> WebSocket 解决实时课堂检测中的持续数据传输问题。

### 这一页要讲清楚

系统不是“先做网页，再随便接一个模型”，而是：

> **先解决模型检测 → 再建立评价算法 → 再封装成 Web 服务 → 再完成数据库和前端集成 → 最后进行系统测试。**

## 第15页｜专注度算法实现路径

### 基础计算方式

```text
不同课堂行为
      ↓
行为人数统计
      ↓
行为权重映射
      ↓
加权计算
      ↓
课堂专注度
```

### 可以展示公式

```text
             Σ(Nᵢ × Wᵢ)
A = ───────────────────── × 100%
                ΣNᵢ
```

其中：

- `Nᵢ`：第 i 类行为人数；
- `Wᵢ`：行为对应权重；
- `A`：课堂专注度。

### 答辩注意

当前权重应称为**初始设计参数**，后续通过实验进一步验证，不要表述为行业标准。
