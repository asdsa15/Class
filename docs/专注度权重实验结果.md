## 5. 实验结论

1. 同一批含非专注行为的样本在 6 组权重方案下的平均专注度相差 10.58 个百分点，其中对低头 / 趴桌权重最敏感的是方案2（0.5）与方案6（0.0），说明权重取值会直接改变专注度数值，需要在论文中明确其为可调的设计参数。
2. 权重变化主要影响含走神行为的课堂：仅含举手、阅读、写作的样本在任何方案下均为 100%，这也说明系统对“专注型课堂”的判断具有一致性。
3. 使用手机权重从 0 上调至 0.2 后，含手机行为的样本专注度明显回升，说明是否把手机行为视为完全非专注，是影响整体得分的关键假设之一。
4. 严格方案（低头、趴桌权重为 0）会把普通低头思考也判为完全不专注，导致课堂专注度整体偏低，与人工观察结果偏差较大，因此不采用。
5. 系统最终采用基线权重（举手 / 阅读 / 写作 1.0，使用手机 0，低头 0.3，趴桌 0.2）：该方案对明显不专注行为（手机、趴桌）惩罚较强，对可能只是短暂低头的学生保留部分分值，在本次样本上平均专注度居中，且课堂之间的评价排序稳定，故作为系统默认参数。
