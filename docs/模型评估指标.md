## 4. 结果分析要点

1. 使用手机、阅读、写作属于姿态特征明显的类别，检测精度相对较高；
2. 低头与靠在桌上在视觉上高度相似（都表现为身体前倾、头部偏低），是主要的混淆来源，
   可从 `confusion_matrix.png` 中看到两类互相误检；
3. 举手、阅读、写作等行为数量多、样本充足，mAP 较高；
   使用手机样本相对较少，属于类别不均衡的典型情况；
4. 遮挡（前排学生挡住后排）与光照变化会降低召回率，
   这也是论文“存在问题”部分可以讨论的内容。
